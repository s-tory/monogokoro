# 用語集 / Glossary / 术语表

日本語が正。`README.md` / `README_EN.md` / `README_CN.md` と `README_DETAIL*.md` は各言語で
自己完結させてあるので、**1 本だけ直すと乖離する。** 訳語を決めたらここに書く。

**「確認」列の意味:**

- **済** — 中国語話者（またはそれに準ずる手順）が検証した。手順は「訳を*生成*させて差分を取る」で、
  「これで合ってる?」と*承認*を求めるのは無効（承認のコストがゼロなので必ず同意が返る）
- **未** — このリポジトリの中で決めただけ。既存語彙との一貫性は grep で確認しているが、
  中国語として自然かは未検証

**誤訳を消さずに残す。** 一度踏んだ穴は、次に同じ形で近づいてくる。

## 文体の約束

**前面の 3 本（`README.md` / `_EN` / `_CN`）は、専門家でない読者が読める平易さを保つ。**
成語や書面語に寄せて「ドキュメントらしく」しない ── 専門的な記述は `README_DETAIL*.md` にある。

2026-09-09 に外部のレビューから「四字熟語を使うと質が上がる」「口語すぎる」という指摘を受けたが、
**却下した**。「誰でも買えるハードウェアと誰でも読めるソフトウェア」の「誰でも」の反復は主張そのもので、
`通俗易懂` に成語化すると平易さが消える。**校閲を依頼するときは読者層を先に伝えること。**
伝えないと、校閲者は「技術文書らしさ」を既定値として補完する。

## 二段訳に注意

`README_CN.md` は英語版を経由して訳された箇所がある。**日→英で慣用的な比喩に化け、英→中で
字面に戻る**という壊れ方をする:

| 日本語                   | English                                 | 壊れた中文                             | 直した中文 |
| ------------------------ | --------------------------------------- | -------------------------------------- | ---------- |
| 最も効いている           | most load-bearing（建築の耐力壁の比喩） | `最吃劲`（力がかかる、の物理的な意味） | `最有效`   |
| 細かく（分解能が上がる） | finer                                   | `变细`（細くなる）                     | `分辨率`   |

**日本語の原文を開かないとこの機序は見えない。** 中文だけを見ても「不自然」までしか言えない。
